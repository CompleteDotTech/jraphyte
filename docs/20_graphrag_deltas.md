# Material architectural change matrix

Baseline: the uploaded `TRACE-GC_Implemented_Project(1).zip`, release 0.3.0. The baseline suite ran 197 tests (196 passed; one exact-pinned external backend test skipped). The baseline documents and reports are retained under `archive/v0.3/`; unchanged earlier v0.2 material remains intact. See `review/graphrag_baseline_audit.json` for source hashes and preserved-test evidence.

| Existing component | GraphRAG extension | Integration point | Why | Risk / trade-off | Validation |
|---|---|---|---|---|---|
| Immutable Catalog and typed records | Ten additive retrieval/access/context/lineage/replay/evaluation record kinds; seven requested conceptual schemas map to existing envelopes. | `catalog.py`, `tools/retrieval_schemas.py`, runtime/wheel schemas. | One provenance graph rather than a parallel record store. | Schema/reference drift. | Strict schema copies, full bundle/lineage tests. |
| Exact source evidence firewall | Graph access/trust checks before candidate construction; canonical reconstruction of retrieved text. | Existing `verify_evidence` plus `retrieval/security.py` and `items.py`. | Retrieved data is not automatically trusted evidence. | Hidden sources, prompt injection, forged graph context. | Pre-embedding ACL and canonical-forgery tests. |
| Complete recursive Evidence Closure | Retrieval-aware bounded source+graph selection; full snapshot remains internal to structural validation. | Optional arguments to `closure`, `materialize`, `compile_pack`. | Limit model context without weakening graph invariants. | Omitted decisive context; token growth. | Closure/materialization, no-graph and stale-context tests. |
| Fixed Question Packing Planner and Jev adapter | Separate versioned relevance question program and optional reranking; current graph ACL required for live retrieved packs. | `programs.py`, `adapter.py`, `reranker.py`. | Use semantics only for bounded usefulness judgments. | Relevance becoming truth; self-reinforcement. | Raw-receipt reconstruction, rerank coverage and no-recursion tests. |
| Existing resolver and acquisition/abstention | Task/risk planner plus finite upstream controller routes INSUFFICIENT to additional retrieval. | Existing solve/project/evaluate calls in `UpstreamGraphRAG`. | Evidence acquisition can exploit existing graph state. | Runaway expansion or answer shopping. | Expansion, saturation, max-round and review-stop tests; scenario D. |
| Existing Decision IR | Derived query/context/result/closure/fingerprint references on packs, observations and resolutions. | Compiler → adapter → resolver → existing plan references. | Explain why evidence reached Jev and a graph commit. | Caller-supplied/forged lineage. | Binding/projection and full causal-ledger validation. |
| Exact qualification applicability | Retrieval configuration changes the packing/materializer scope and immutable semantic input. | Existing qualification context; no new acceptance shortcut. | Old calibration cannot silently authorize a changed pipeline. | Excessively broad reuse or costly requalification. | Legacy versus retrieved qualification-scope tests. |
| SQLite authority, snapshots and journal | Read-only consistent graph adapter; memory fixture adapter; store-independent strategy protocol. | Existing backend state/catalog/status/journal; no second writer. | Retrieve current/historical graph and source arrival state. | Stale or unavailable snapshots; scan cost. | Commit visibility, rollback, as-of and source-arrival tests. |
| Existing plan source preconditions | Retrieved closure sources participate in required-source epoch/hash checks. | `plans.required_sources`; existing preflight/transaction CAS. | Evidence used for synthesis cannot evade source revocation at publication. | Conservative full structural-source closure can block a plan. | Existing plan/transaction suite plus provenance/withdrawal scenarios. |
| Existing history and decision ledger | Query rejected/abstained/unresolved hypotheses, superseded assertions and provenance; store retrieval selection/discard reasons. | Existing records and journal, `retrieval-lineage`, graph modes. | Make graph change and non-addition inspectable. | History mistaken for current truth or unauthorized data. | Hypothesis separation, temporal/superseded and permission tests. |
| No first-class downstream query facade | Provenance/contradiction-aware GraphRAGAnswerContext service over compiled evidence. | Shared HybridRetriever, read-only downstream role. | Supply cited contexts to search/QA/agents and new synthesis requests. | Unsupported prose or leaked internal Catalog. | Exact source citations, role binding, no-write and scenario A–D tests. |
| Existing monotonic run budgets | Retrieval dimensions, logical work/deadline checks, atomic conflict-pair budgeting and scoped LRU. | Shared `RunBudget`; `BudgetMeter`; snapshot/ACL identity. | Bound traversal and repeated overlapping queries. | Partial retrieval, cooperative deadlines, stale caches. | Resource caps, pair-budget, revocation and cache tests. |
| Existing immutable replay | New retrieval branch can alter strategy/snapshot/ranking and emit new observations. | `replay_retrieval` alongside existing policy replay. | Compare retrieval changes without rewriting historical inference. | Counterfactual relabeling; missing historical sources. | Old receipt preservation and changed-hop/version tests. |
| Existing evaluation and optional research protocol | Retrieval/synthesis/efficiency metrics, 91-run synthetic ablations, failure-driven proposals and locked holdout gate. | `retrieval/evaluation.py`, `benchmark.py`, existing policy safeguards. | Measure quality and research changes, not just retrieval output. | Toy results mistaken for production performance; holdout leakage. | Metric vectors, leakage/safety gates, explicit null real-model metrics. |

The Evidence Firewall, semantic-versus-confidence separation, claim binding, resolver, calibration machinery, source withdrawal, signed authorization, reversible transactions and original evaluation safeguards were **already present**. This release extends their interfaces and inputs; it does not relabel them as new GraphRAG inventions.
